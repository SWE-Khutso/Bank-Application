# Codveda Bank - Console Bank Application

A simple menu-driven bank app in Java that runs in the console.

## Features
- Show balance
- Deposit money
- Withdraw money (blocks withdrawals above the balance)
- Rejects zero or negative deposits
- Runs until the user chooses Exit

## How to run
1. Open the project in NetBeans.
2. Run `Bank_Application.java`.
3. Type a menu number and press Enter.

## Menu
```
1. Show Balance
2. Withdraw
3. Deposit
4. Exit
```
